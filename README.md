# 🌐 Portfólio Pessoal - Bruno Ferreira

Bem-vindo ao meu portfólio!  
Este projeto foi desenvolvido para apresentar minhas habilidades, experiências e projetos de forma moderna, responsiva e interativa.

---

## 🚀 Tecnologias Utilizadas
- ⚛️ **React** – construção de interfaces dinâmicas
- 🟦 **TypeScript** – tipagem estática para maior confiabilidade
- ⚡ **Vite** – ambiente de desenvolvimento rápido
- 🎨 **Tailwind CSS** – estilização com utilitários
- 🧩 **shadcn/ui** – componentes prontos e acessíveis
